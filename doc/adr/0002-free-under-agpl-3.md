# 0002 — Free, under AGPL-3.0, like altioo-mcp

- Date: 2026-10-28
- Decided by: Guy Couronne
- Status: accepted

`altioo-oauth-server` is free and licensed AGPL-3.0, the same as altioo-mcp, the extension it
protects first. There is no paid edition and no licence check in the code.

Rejected: a paid companion to the free base.

Enforced by: `LICENSE` holds the AGPL-3.0 text. Nothing yet checks that the module manifest
declares the same licence.
